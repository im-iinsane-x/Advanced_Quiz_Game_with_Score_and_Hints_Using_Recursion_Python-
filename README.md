# Advanced_Quiz_Game_with_Score_and_Hints_Using_Recursion_Python-
An interactive command-line Quiz Game built with Python that uses recursion instead of loops, featuring score tracking, hints, retry functionality, and dynamic performance feedback.

Project Purpose

This project was developed to explore recursion through a practical quiz application. It demonstrates how recursive function calls can effectively manage program flow while providing an engaging user experience with scoring, hints, and performance feedback.
